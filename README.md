# Pakistan Gum Industries (Pvt.) Ltd.

A modern, responsive company website for Pakistan Gum Industries (Pvt.) Ltd., showcasing the company's products, facilities, certifications, and corporate policies.

## Website Sections

- **Home** — Company introduction and hero slider.
- **About** — Company information.
- **Facilities** — Manufacturing, handling, packaging, storage, quality control, food safety, and hygiene practices.
- **Certification** — ISO 9001:2015, FSSC 22000, and other certification-related information.
- **Policies** — Quality, food safety, health and safety, halal, environmental, and workplace policies.
- **Product** — Guar Seed, Guar Splits, Guar Gum Powder, and Guar Meal.
- **Contact** — Company contact information.

## Technologies Used

- Next.js
- React
- JavaScript
- CSS
- Lucide React
- EmailJs

## Getting Started

Install the project dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Features

- Responsive design for desktop, tablet, and mobile.
- Reusable React components.
- Interactive navigation and hover effects.
- Product and certification showcases.
- Dedicated facilities and policy sections.

## Deployment

The website can be deployed using [Vercel](https://vercel.com/) or another platform that supports Next.js.
